# Wordle ASCII Game

A Wordle-inspired game developed in Java using an ASCII-based interface, with integrated database functionality for storing and managing game data.

---

## Overview

This project was my first major step in learning Java and software development. It focuses on core programming concepts, including input handling, game logic, and data persistence.

The game runs entirely in the console, using ASCII output to represent gameplay and provide user feedback.

---

## Features

* Word guessing game inspired by Wordle
* ASCII-based console interface
* Input validation and feedback system
* Database integration for storing game-related data

---

## Technologies Used

* Java
* JDBC / Database integration
* Git & GitHub

* Strengthened understanding of core Java concepts
